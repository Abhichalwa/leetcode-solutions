## Problem: Valid Anagram (Easy)

**Link:** https://leetcode.com/problems/valid-anagram/

### Approach

I used a frequency-counting approach to compare the characters in both strings. The character counts are increased for the first string and decreased for the second string.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

The solution checks whether both strings contain the same characters with the same frequencies.
